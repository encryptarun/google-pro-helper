=======================================================================
  Google AI Pro (5 TB) Two-Year Zero-Cost (US$0.00 -> 24 months) Automated Console
=======================================================================

[Environment requirements]
1. macOS 12 or later
2. Google Chrome installed (the default path is fine)
3. Python 3.10 or later installed
4. Network: use a US proxy on this machine, or enter a proxy template in the left side of the console

[Quick start]
1. On first use, double-click: [1_install_and_start.command]
2. For everyday use, double-click: [2_start_console.command]
3. The browser will open the console at: http://127.0.0.1:8765

[Payment card setup and account workflow]
1. Enter a payment card (required):
   - In the "Global Configuration and Inline Tax-Exempt Card Setup" area on the left, enter your own international Visa or Mastercard:
     * Card number (16 digits)
     * Expiration date (month / year, e.g. 08 / 29)
     * Security code (3-digit CVC)
     * Cardholder's name in English
     * The tax-exempt ZIP code is preset to 97201 (Oregon, US); no change is needed
   - Click [Save Configuration].
   - Note: The script has strict US$0.00 purchase protection and clicks Subscribe only when the checkout dialog confirms US$0.00. The original instructions claim there will be no charge; actual charges and benefits depend on checkout and upstream results.

2. Import Google accounts in bulk:
   - Paste accounts (one per line) in the "Bulk Account Import" area on the right. Any of these formats are supported:
     * email----password----recovery email
     * email----password----recovery email----2FA secret
     * email----password----2FA secret
   - Click [Import Account List].

3. Start automated execution:
   - Click [Run] next to one account, or [Run All Automatically] at the top.
   - The script will:
     Step 1: Sign in to Google and complete recovery-email / 2FA verification
     Step 2: Set up a card with inline tax exemption + the first 12-month package (US$0.00)
     Step 3: Add a second 6-month package (US$0.00 -> 18 months)
     Step 4: Add a third 6-month package (US$0.00 -> capped at 24 months)
     Step 5: Go to Google Play to cancel auto-renewal, preserve the two-year expiration benefit, and capture a verification screenshot
